API Reference

JSON-RPC endpoint with full Ethereum compatibility. All requests are POST to the RPC URL.

Ethereum Standard Methods

eth_chainId
Returns the chain ID (424242 = 0x67932)
{"jsonrpc":"2.0","id":1,"method":"eth_chainId","params":[]}
eth_blockNumber
Returns the latest block height as hex
{"jsonrpc":"2.0","id":1,"method":"eth_blockNumber","params":[]}
eth_getBalance
Returns the balance of an address in wei
{"jsonrpc":"2.0","id":1,"method":"eth_getBalance","params":["0xADDRESS","latest"]}
eth_getTransactionCount
Returns the nonce (transaction count) for an address
{"jsonrpc":"2.0","id":1,"method":"eth_getTransactionCount","params":["0xADDRESS","latest"]}
eth_getBlockByNumber
Returns a block by height. Set second param to true for full tx objects.
{"jsonrpc":"2.0","id":1,"method":"eth_getBlockByNumber","params":["latest",false]}
eth_getTransactionReceipt
Returns a transaction receipt by hash
{"jsonrpc":"2.0","id":1,"method":"eth_getTransactionReceipt","params":["0xHASH"]}
eth_call
Executes a read-only EVM call
{"jsonrpc":"2.0","id":1,"method":"eth_call","params":[{"to":"0xCONTRACT","data":"0xCALLDATA"},"latest"]}
eth_sendRawTransaction
Submits an ECDSA-signed Ethereum transaction (from MetaMask)
{"jsonrpc":"2.0","id":1,"method":"eth_sendRawTransaction","params":["0xSIGNED_TX_HEX"]}
eth_gasPrice
Returns the current gas price
{"jsonrpc":"2.0","id":1,"method":"eth_gasPrice","params":[]}
net_version
Returns the network version (chain ID as string)
{"jsonrpc":"2.0","id":1,"method":"net_version","params":[]}

Zeno Native Methods

get_chain_status
Returns full chain status including metadata and peer info
{"jsonrpc":"2.0","id":1,"method":"get_chain_status","params":[]}
get_staking_state
Returns current staking state with all validators
{"jsonrpc":"2.0","id":1,"method":"get_staking_state","params":[]}
get_governance_state
Returns governance parameters and pending proposals
{"jsonrpc":"2.0","id":1,"method":"get_governance_state","params":[]}
faucet_send
Sends testnet ZPQ to an address
{"jsonrpc":"2.0","id":1,"method":"faucet_send","params":["0xADDRESS","1000000000000000000"]}
register_validator
Registers a new validator with the network
{"jsonrpc":"2.0","id":1,"method":"register_validator","params":[{"public_key":"HEX","p2p_address":"IP:PORT","rpc_address":"IP:PORT","self_bond":1000000}]}

Zero-Knowledge Methods

zk_shield
Deposits value into the shielded pool
{"jsonrpc":"2.0","id":1,"method":"zk_shield","params":[{"value":1000,"commitment":"0xHASH"}]}
zk_unshield
Withdraws value from the shielded pool
{"jsonrpc":"2.0","id":1,"method":"zk_unshield","params":[{...}]}
zk_pool_info
Returns shielded pool state
{"jsonrpc":"2.0","id":1,"method":"zk_pool_info","params":[]}
