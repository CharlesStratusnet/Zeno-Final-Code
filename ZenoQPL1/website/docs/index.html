Run a Validator Node

git clone https://github.com/CharlesStratusnet/Zeno-Final-Code.git
cd Zeno-Final-Code/ZenoQPL1
cargo build --bin zeno-cli --release
./target/release/zeno-cli node init-solo --output ./devnet --chain-id zeno-mainnet
RUST_LOG=info ./target/release/zeno-cli node start \
  --config ./devnet/node-0/node.toml \
  --genesis ./devnet/genesis.json

Deploy a Smart Contract

Zeno is fully EVM compatible. Use Remix, Hardhat, or Foundry — just point to the Zeno RPC URL.

// hardhat.config.js
module.exports = {
  networks: {
    zeno: {
      url: "https://rpc.zenopq.com",
      chainId: 424242,
    }
  }
};

Verify a Post-Quantum Signature in Solidity

function verifyPQ(
    bytes memory pubKey,
    bytes memory message,
    bytes memory signature
) public view returns (bool) {
    bytes memory input = abi.encode(pubKey, message, signature);
    (bool ok, bytes memory result) = address(0x10001).staticcall(input);
    return ok && result[31] == 0x01;
}
